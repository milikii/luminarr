# Library Truth Model

Captured from user-provided production library layout.

- Movies live under `Movie/<片名> (<年份>)/`
- TV / Anime live under `TV|Anime/<剧名> (<年份>)/Season N/`
- NFO is the authoritative metadata layer
- Poster / backdrop / banner / thumb / logo / clearlogo / clearart / disc / art are first-class assets
- Video and subtitle basenames may mix languages and must not be the only truth source
